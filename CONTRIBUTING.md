# Contributing to Len Courier Services

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/len-courier-services.git`
3. Create a feature branch: `git checkout -b feature/YourFeature`
4. Make your changes
5. Commit: `git commit -am 'Add YourFeature'`
6. Push: `git push origin feature/YourFeature`
7. Submit a pull request

## Code Style

- Use consistent indentation (2 spaces)
- Follow JavaScript/React conventions
- Use meaningful variable names
- Add comments for complex logic
- Use ESLint for code quality

## Commit Messages

- Use clear, descriptive commit messages
- Start with a verb: "Add", "Fix", "Update", "Remove"
- Example: "Add parcel tracking feature"

## Pull Request Process

1. Update documentation as needed
2. Ensure all tests pass
3. Update CHANGELOG.md
4. Request review from maintainers
5. Address feedback and comments

## Reporting Bugs

- Check if bug already exists
- Provide detailed reproduction steps
- Include environment info
- Add screenshots if applicable

## Feature Requests

- Describe the feature clearly
- Explain the use case
- Provide examples if applicable
